# SK Fen Bilimleri — Web Sitesi

SK Fen Bilimleri (Küçükyalı, Maltepe) ana sayfa tasarımı. Tek sayfalık, statik HTML/CSS/JS.

## Çalıştırma

Klasörde basit bir sunucu başlatıp tarayıcıda açın:

```bash
python3 -m http.server 8000
```

Ardından http://localhost:8000 adresine gidin.

## Görseller

Tüm görseller `gorseller/` klasöründe. Hangi dosyanın sayfada nerede kullanıldığı `gorseller/BENIOKU.txt` içinde yazıyor; aynı isimle değiştirmek yeterli.

## Ayarlar

- WhatsApp numarası ve hazır mesaj: `index.html` içinde `WHATSAPP_NUMARA` ve `WHATSAPP_MESAJ`.
- Seviye belirleme formu henüz bir sisteme bağlı değil.
- Sayfa şu an `noindex, nofollow` (arama motorlarında görünmez).

## Notlar

- Görsellerin bir kısmı temsilidir; yayından önce gerçek SK fotoğraflarıyla değiştirilecek.
- Atomica görselleri ve logosu Atomica'ya aittir; yayından önce kullanım onayı alınmalıdır.
